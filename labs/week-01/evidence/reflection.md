# LAB 01 Reflection

ฉันได้ตรวจสอบ Node.js, npm และ Git บนเครื่องของตนเอง
และทดลองรัน JavaScript ผ่าน npm scripts

ฉันได้เรียนรู้ว่า branch ช่วยแยกงานออกจาก main,
commit ใช้บันทึกการเปลี่ยนแปลง และ Pull Request ใช้เสนอ
การเปลี่ยนแปลงเพื่อตรวจสอบก่อน merge

ผลการทดสอบ npm install, npm run start และ npm run check ผ่านแล้ว
ขั้นตอนต่อไปคือ build, verify, push และส่ง Pull Request
