# ระบบจัดการพัสดุหอพัก

## วิธีใช้งาน
เปิดไฟล์ `index.html` ด้วย Chrome หรือ Edge

## ฟังก์ชัน
- Dashboard จำนวนพัสดุทั้งหมด รอรับ รับแล้ว และค้างเกิน 3 วัน
- เพิ่ม แก้ไข ลบรายการพัสดุ
- เก็บชื่อผู้รับ ห้อง เบอร์โทร เลขพัสดุ บริษัทขนส่ง วันที่เข้า และหมายเหตุ
- เปลี่ยนสถานะรับพัสดุและย้อนสถานะได้
- ค้นหาและกรองตามสถานะ
- เก็บข้อมูลใน localStorage ให้คงอยู่หลังรีเฟรช

## ข้อจำกัด
เวอร์ชันนี้เป็นเว็บแอปต้นแบบที่เก็บข้อมูลในเบราว์เซอร์ ยังไม่มีฐานข้อมูลส่วนกลางหรือระบบล็อกอิน ควรตรวจเทียบข้อกำหนดงานของอาจารย์ก่อนส่ง
