# ข้อตกลงของทีม (Team Contract) - T15 ระบบสั่งพิมพ์งาน

## รายชื่อสมาชิกในทีม
1. ปริยากร ธารพรศรี (รหัสนักศึกษา 68543210078-0)
2. นรินทร์ ไสวจำเนียรกุล (รหัสนักศึกษา 68543210030-1)


## ข้อตกลงการทำงานร่วมกัน
1. **การแบ่งงาน**: สมาชิกทุกคนจะแบ่งหน้าที่กันรับผิดชอบอย่างชัดเจน ทั้งส่วน Back-end, Front-end และการทดสอบระบบ
2. **การใช้ Git & GitHub**: จะต้องสร้าง Branch แยกของใครของมันเวลาทำฟีเจอร์ และต้องทำ Pull Request (PR) พร้อมให้เพื่อนในทีมรีวิวก่อน Merge ทุกครั้ง
3. **การสื่อสาร**: พูดคุยและอัปเดตความคืบหน้าผ่านกลุ่มไลน์ของทีมอย่างสม่ำเสมอ หากติดปัญหาต้องรีบแจ้งกันทันที
